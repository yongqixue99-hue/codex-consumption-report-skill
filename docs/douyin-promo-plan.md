# Codex Consumption Report Skill 抖音宣传方案

更新时间：2026-08-04

成片规格：9:16 竖屏、1080 × 1920、30 fps、建议 40 秒

成片类型：本人短口播 + 报告录屏；不制作动态演示 MP4，不使用真实账户数据

## 这条视频讲什么

Codex 账户页能看到 Token 总量，却很难回答“哪一天、哪个项目、哪个模型用了多少”。这个开源 Skill 处理用户明确提供的 Codex / CC Switch 数据，在本地生成一份可以按日期筛选的自包含 HTML 报告，并把数据覆盖范围写清楚。

视频只承诺报告能够解释输入数据，不承诺找回已经删除且没有留下历史账本的线程，也不把 API 等价成本说成订阅账单或剩余额度。

## 录屏操作顺序

1. 打开匿名演示报告，浏览器缩放设为 125%–140%，确保竖屏裁切后日期与数字仍可读。
2. 首屏停 1.5 秒，让观众看清统计日期、Token、调用和会话。
3. 点击“最近 7 天”，确认趋势图横坐标显示实际日期，所有标题同步变成所选日期范围。
4. 在每日趋势的峰值点停留 0.8 秒，展示日期、Token 和调用 tooltip。
5. 向下滚动，只保留项目、模型、缓存和调用时段四个最直观的视图；每个视图停 0.8–1.2 秒。
6. 结束前回到报告 Hero，画面上只保留项目名、开源状态和使用入口。

- 竖屏 9:16，1080 × 1920，30 fps；人脸和关键数字放在中间 60% 安全区。

## 演示数据与隐私处理

1. 只使用仓库内的匿名合成 fixture，或专门复制并脱敏的数据文件；不要直接录制个人 Codex 账户页、CC Switch 数据库或真实报告。
2. 删除提示词、代码、邮箱、UUID、设备名、绝对路径、Git 远端和可反推客户的信息。
3. 项目名改为中性假名，例如 `Project Atlas`、`Project Harbor`；会话名使用报告生成的假名。
4. 不展示真实累计 Token、连续使用天数、账户昵称或头像。数字需要演示时，使用竞赛包固定的匿名演示结果，避免前后镜头对不上。
5. 输入文件只在本机读取；报告生成链不主动上传输入文件。若通过第三方平台运行，原始上传文件的留存由平台或调用方管理，视频文案不能承诺平台一定删除原文件。
6. 导出成片后逐帧检查终端首尾、tooltip、浏览器地址栏和系统菜单栏；发现真实标识就重新录制，不使用模糊贴片勉强遮挡。

## 评论区 FAQ

### 1. 数据从哪里来？

本机完整版可以处理用户明确提供的 Codex / CC Switch / CodeBurn 数据；竞赛便携版只接受包内匿名演示，或显式上传且已经脱敏的 JSON、JSONL、CSV。它不会自动登录账户或扫描其他设备。

### 2. 同一个账号在 Mac 和 Windows 上使用，为什么少一部分？

账号相同不代表本地项目明细会自动同步。需要分别导出两台设备可用的历史账本，再合并和去重；没有导入的设备只能留在官方账户总量里，不能分配到具体项目。

### 3. 删除过的线程还能恢复项目分类吗？

如果 CC Switch、CodeBurn 或其他历史账本仍保留相关记录，报告可以使用剩余明细。线程和历史记录都已经删除时，无法从账户总量反推出项目、任务或会话。

### 4. 为什么报告总量和官方账户页不完全一致？

官方账户总量与本地可恢复明细是两个统计层。未导入的设备、被删除的历史记录和不同的数据保留范围都可能形成缺口，报告不会把缺口擅自归到某个项目或设备。

### 5. 报告里的金额是我的 Codex 账单吗？

不是。金额按公开 API 价格做等价估算，用于比较用量结构，不是 Codex 订阅账单，也不表示剩余额度。

### 6. 会读取提示词和代码吗？

生成报告不需要展示提示词或源代码。公开演示只使用匿名数据，报告默认不嵌入提示词、代码、原始 UUID 和用户绝对路径。

### 7. 可以二次开发吗？

项目原创代码按 Apache License 2.0 开放使用、修改和再分发。分发包里包含的 ECharts、d3、zrender、tslib 继续遵守各自许可证，并保留对应版权与 NOTICE。

### 8. 这是 OpenAI 官方产品吗？

不是。这是独立开发的开源 Skill，Codex 和 OpenAI 名称仅用于说明兼容的数据与使用场景。
